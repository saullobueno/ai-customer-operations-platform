# Inbox e Ticket

## Inbox

Layout de três colunas:

1. filtros/views
2. lista de tickets
3. conversa

Filtros:

- status
- priority
- assignee
- team
- channel
- tags
- SLA
- customer
- date
- AI classification
- custom fields

Cada item mostra avatar, nome, assunto, preview, horário, prioridade, SLA, canal e unread.
